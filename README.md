# PALFA RRAT example code
This is a repository with example code for the single pulse analysis of PALFA single pulse data performed in Doskoch et al. 2026 (submitted to ApJ). The /notebooks subdirectory contains Jupyter notebooks demonstrating parts of the single pulse analysis using simulated data. The /profiles subdirectory contains individual real single pulses from J2010+31, one of the sources in the paper, stored as .txt files. The notebooks can be easily adapted to read in these files instead of simulating data.
